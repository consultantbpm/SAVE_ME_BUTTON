Save Me Button은 Wear OS 시계를 나만의 긴급 버튼으로 바꿔 줍니다. 도움이 필요할 때 시계의 물리 버튼을 길게 누르기만 하면 긴급 시퀀스가 시작됩니다. 손목 위에서 바로 처리됩니다.

작동 방식
버튼을 길게 누르면 Save Me Button이 다음을 수행합니다:
- 위치가 담긴 SMS(GPS 좌표와 지도 링크)를 비상 연락처로 전송
- 최대 3명의 연락처에 차례로 전화
- 누군가 받을 때까지 통화를 반복

시계에 자체 셀룰러 연결이 있으면 모든 것이 시계에서 직접 실행됩니다. 그렇지 않으면 폰 컴패니언 앱을 통해 작동합니다. 어느 쪽이든 도움은 버튼 하나 길게 누르면 됩니다.

빠른 취소
실수로 작동시켰나요? 몇 번의 탭만으로 전체 시퀀스를 취소할 수 있습니다.

긴급 알림은 항상 무료
SOS 긴급 기능은 영원히 무료이며 결제 장벽 뒤에 잠기는 일이 절대 없습니다. SMS 전송, 연락처 통화, 자동 반복 에스컬레이션은 언제나 무료로 작동합니다. 당신의 안전은 프리미엄 기능이 아닙니다.

선택형 잠금 해제
2.99 유로의 일회성 구매로 잠금 해제되는 것은 단 하나의 편의 기능뿐입니다. 긴급 SMS 메시지의 문구를 직접 편집할 수 있게 됩니다. 안전과 관련된 모든 기능은 무료로 유지되며, 이 잠금 해제는 전적으로 선택 사항입니다.

폰 컴패니언 앱
연락처와 메시지는 폰 컴패니언 앱에서 설정하고, 나머지는 시계에 맡기세요.

Save Me Button을 선택하는 이유
시계 버튼으로 작동하는 SOS로, SMS에서 통화로 자동으로 확대되며 누군가 받을 때까지 계속 시도합니다. 게다가 긴급 알림은 항상 무료로 유지됩니다.

Save Me Button을 추가하고 손목에 안전망을 지니세요.
